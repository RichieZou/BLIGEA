# BLIGEA

This is the code for the paper:

**A Sparse Large-scale Multi-objective Evolutionary Optimization based on Bi-level Interactive Grouping**\
Yingjie Zou, Juan Zou, Shiting Wang, Yuan Liu, Shengxiang Yang\
*Swarm and Evolutionary Computation*, vol. 99, Art. no. 102209, 2025. [[Paper]](https://doi.org/10.1016/j.swevo.2025.102209)

## Requirements

The platform to run this code is [PlatEMO](https://github.com/BIMK/PlatEMO) 4.1 and above.
